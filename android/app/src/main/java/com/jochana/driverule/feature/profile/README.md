# 운전자 프로필

이름 등록·건너뛰기·프로필 선택/변경을 구현할 위치다. Screen/Route/ViewModel/UiState를 기능 안에 둔다. 이름 입력은 차량 UX 제한이 해제된 경우에만 허용한다. 저장은 repository를 통해 차량 내부 Room에 연결한다. 현재 기능 구현 없음.

기본 MVVM/UDF와 명시적 함수로 구현하고 범용 MVI store를 도입하지 않는다. 최대 3명 제약은 저장 트랜잭션에서도 보장한다. 프로필 변경은 진행 중 안내의 맥락을 무효화하도록 안내 coordinator에 전달하며 이력을 이전 운전자와 섞지 않는다.
