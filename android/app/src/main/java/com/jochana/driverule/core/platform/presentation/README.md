# 카드 표시 adapter

공식 지원과 허용 범위를 확인한 카드 표시 surface의 구현 위치다. 현재 구현과 표시 권한 없음.

- domain의 출력 port를 구현하고 요청 수락, 실제 표시, 닫힘, 실패를 구분해 돌려준다.
- 안내 ID·실행 세대와 출력 핸들을 연결하여 같은 요청의 중복 표시와 취소 후 뒤늦은 표시를 방지한다.
- 표시 adapter는 자체적으로 안내를 선택하거나 타이머·재시도 정책을 소유하지 않는다. coordinator의 명령에 따라 자기 안내의 자원만 정리한다.
- `feature/driving`은 앱 화면에서의 표현 책임을 맡는다. 시스템 알림/카드의 실제 표현 방식과 재사용 범위는 지원 API 확인 뒤 정한다.
- 임의 overlay나 background Activity 실행으로 표시 경로를 대체하지 않는다.
