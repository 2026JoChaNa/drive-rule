# 화면 움직임 명세

작성일: 2026-11-14 · 상태: 앱에서 설계한 값 (디자이너 검토 대기)

Figma로는 움직임을 정의하기 어렵습니다. 그래서 움직임은 앱에서 설계하고 이 문서에 남깁니다. 디자이너는 이 문서를 검토하고, 값을 바꿀 때도 이 문서를 고칩니다. 코드는 두 곳에 있습니다.

- 화면 전환 · 알림 · 시트: `android/app/src/main/java/com/jochana/driverule/ui/components/DriveRuleMotion.kt`
- 카드 장면: `android/app/src/main/java/com/jochana/driverule/feature/card/SceneScript.kt` (각본) · `AnimatedCardScene.kt` (그리기)

## 원칙

1. **차량 화면이라 짧고 조용하게.** 움직임은 '바뀌었다'를 알리는 데까지만 씁니다. 전환은 모두 300ms 안에서 끝납니다
2. **장면은 한 번 재생하고 멈춥니다.** 끝없이 반복하지 않습니다. 장면을 누르면 다시 재생합니다(접근성 동작 '장면 다시 보기')
3. **물리적으로 말이 되게.** 차는 바라보는 방향으로만 가고, 돌 때는 곡선을 따라 돌며 차 방향이 곡선을 따릅니다. 보행자는 횡단보도를 가로질러 건넙니다
4. **마지막 장면은 Figma 원본 프레임입니다.** 그래서 애니메이션을 꺼도(정지 그림) 같은 장면을 봅니다
5. **'애니메이션 삭제' 설정을 따릅니다.** 켜져 있으면 장면은 정지 그림, 전환은 즉시 바뀝니다

## 곡선 (Material 3)

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| Standard | `cubic-bezier(0.2, 0, 0, 1)` | 화면 이동, 배경 어두워짐 |
| Emphasized decelerate | `cubic-bezier(0.05, 0.7, 0.1, 1)` | 들어오는 것(알림, P 아이콘, 파문) |
| Emphasized accelerate | `cubic-bezier(0.3, 0, 0.8, 0.15)` | 나가는 것 |
| 제동 (Brake) | `cubic-bezier(0, 0, 0.2, 1)` | 차가 다가와 서기 |
| 출발 (Pull away) | `cubic-bezier(0.4, 0, 1, 1)` | 차가 서 있다 떠나기 |
| 보행 (Standard ease) | `cubic-bezier(0.4, 0, 0.2, 1)` | 보행자, 강조 |

## 1. 화면 전환

| 경우 | 방식 | 시간 |
|---|---|---|
| 홈 → 달라지는 교통법규 → 카드 상세 (안으로) | **같은 축 이동.** 새 화면이 오른쪽 30dp에서 밀려 들어옴, 이전 화면은 왼쪽으로 30dp 밀려남 | 이동 300ms (Standard). 이전 화면은 처음 90ms에 사라지고, 새 화면은 90ms 뒤부터 210ms 동안 나타남 |
| 뒤로 | 같은 방식, 방향만 반대 | 같음 |
| 처음 설정 → 권한 안내 → 홈 | **페이드 스루.** 이전 화면이 사라진 뒤 새 화면이 96%→100%로 커지며 나타남 | 90ms + 210ms |
| 운전 중 제한 화면으로 바뀜 | 움직임 없이 즉시 | — |

이전 화면이 먼저 사라진 뒤 새 화면이 나타나므로, 두 화면이 반투명하게 겹치는 구간이 없습니다.

## 2. 출발 전 알림 · 근거 시트

| 대상 | 들어올 때 | 나갈 때 |
|---|---|---|
| 출발 전 알림 카드 | 280ms, Emphasized decelerate. 아래 24dp에서 올라오며, 왼쪽 아래 모서리를 기준으로 96%→100%로 커지고, 투명도 0→1 | 180ms, Emphasized accelerate. 아래로 8dp 내려가며 흐려짐 |
| 근거 시트 | 스프링(튕김 없음, 중간-낮은 강성, 약 0.5초)으로 아래에서 올라옴 | 200ms, Emphasized accelerate로 내려감 |
| 시트 뒤 배경 | 250ms 어두워짐 (Standard) | 200ms 밝아짐 |

알림이 자동으로 닫히는 8초와 진행 막대는 그대로입니다.

## 3. 카드 장면

각 장면은 **다가옴 → 멈춤(법규 포인트) → 안전하게 진행 → 원본 프레임으로 정착** 순서입니다. 모두 카드 자동 닫힘(8초) 안에 끝납니다. 좌표는 Figma 장면 크기(759 × 677 px) 기준입니다.

### H-1 신호등 없는 횡단보도 — 5.6초

| 시간 | 일어나는 일 |
|---|---|
| 0 ~ 1.5초 | 차가 아래에서 260px 다가와 정지선 앞에 섬 (제동) |
| 1.1 ~ 1.4초 | 정지선이 빨갛게 켜짐 |
| 1.5 ~ 2.7초 | 멈춰 있음 (사람이 없어도 멈춤) |
| 2.6 ~ 2.9초 | 정지선 강조가 꺼짐 |
| 2.7 ~ 4.9초 | 출발: 99px 직진 → 반지름 150px 우회전(90°) → 동쪽 차로로 360px 직진하며 화면 밖으로 (출발 곡선) |
| 5.2 ~ 5.6초 | 차와 정지선 강조가 원래 자리에 서서히 나타나 원본 프레임이 됨 |

### I-1 우회전 후 횡단보도 — 6.1초

| 시간 | 일어나는 일 |
|---|---|
| 0 ~ 1.5초 | 차가 서쪽에서 500px 다가와 빨간 정지 위치 앞에 섬 (제동). 보행자는 북쪽 끝에서 기다림 |
| 1.3 ~ 3.7초 | 보행자가 횡단보도를 북에서 남으로 건넘 (보행 곡선) |
| 1.5 ~ 3.8초 | 차는 멈춰 있음 |
| 3.8 ~ 5.6초 | 보행자가 다 건넌 뒤 차가 동쪽으로 520px 직진해 화면 밖으로 (출발) |
| 5.7 ~ 6.1초 | 차와 보행자가 원래 자리(보행자는 횡단보도 위)에 서서히 나타남 |

Figma의 I-1 키프레임은 H-1 값에 0.9714를 곱한 복사본이라, 차가 길 없는 곳으로 가고 보행자가 횡단보도를 길게 따라 걸었습니다. 그래서 쓰지 않고 위 각본으로 바꿨습니다.

### A-1 고속도로 정차·주차 — 2.6초

| 시간 | 일어나는 일 |
|---|---|
| 0 ~ 1.8초 | 차가 차로(x 400)에서 올라오다 두 번의 반대 곡선(각 40°, 같은 반지름)으로 갓길에 들어가 섬 (제동) |
| 1.7 ~ 2.0초 | P 아이콘이 60%→100%로 커지며 나타남 |
| 2.1 ~ 2.5초 | 단속 카메라 렌즈가 한 번 번쩍임 (흰 빛 0.15초 켜짐, 0.25초 꺼짐) |

### B-1 목적지 보호구역 — 1.4초

목적지 점에서 '반경 300m' 원까지 파문이 한 번 퍼집니다 (Emphasized decelerate). 색은 지도의 보호구역 색(`#FF4D4F`)이고 0.2초 뒤부터 흐려집니다.

## 부드럽게 보이게 하는 구현

- 차는 직선과 원호로 된 경로 위의 거리로 움직이고, 차 방향은 경로의 접선입니다. x · y · 회전을 따로 움직이지 않습니다
- 움직이는 값은 그리기 단계(`graphicsLayer`, `drawBehind`)에서만 읽습니다. 재생 중에 화면 구성이 다시 일어나지 않습니다
- 그림(SVG)은 처음 한 번 그려 두고, 재생 중에는 위치 · 회전 · 투명도만 바뀝니다

## 디자이너에게 확인할 것

- 화면 전환 방식(같은 축 이동 / 페이드 스루)과 시간
- 장면 각본: 특히 H-1의 '멈춰 있는 시간 1.2초', I-1 보행자 속도, A-1 카메라 번쩍임 세기
- 장면을 반복하지 않고 한 번 재생하는 방식
