# Pleos SDK 상황 신호 정리

2026-11-11

개정 카드에 '우회전' 같은 상황 분류를 저장해 두고 그 상황일 때 안내하려면, 차에서 상황을 알아낼 신호가 필요합니다. Pleos Connect SDK 의 NaviHelper·Vehicle·FusedLocation 에서 쓸 수 있는 신호와 없는 신호를 정리했습니다.

## 쓸 수 있는 신호

상황 분류에 가장 쓸모 있는 것은 NaviHelper 의 회전 안내(TBT)와 주의 지점입니다. 권한은 모두 보호 수준 normal 이라 매니페스트 선언만 하면 됩니다.

| SDK | 정보 | 주요 값 | 받는 방법 | 권한 | 상황 분류 예 |
| --- | --- | --- | --- | --- | --- |
| NaviHelper | 다음 회전 안내 (TBT) | 회전 종류 · 남은 거리(m) · 안내 문구 | `getTBTInfo` / `onTBTInfo` | `NAVI_ROUTE` | 우회전·좌회전·유턴·회전교차로·IC 진입/진출·터널·톨게이트·휴게소 |
| NaviHelper | 주의 지점 | 종류 · 남은 거리(m) | `onCautionPointInfo` | `NAVI_ROUTE` | 어린이보호구역, 꼬리물기·신호위반·버스전용차로·끼어들기 단속, 철도건널목, 과속방지턱, 고속도로 공사, 좁은 길, 주정차 금지, 안개·낙석·역주행 등 24종 |
| NaviHelper | 단속 카메라 | 종류(고정·이동·구간·스쿨존·신호) · 제한속도 · 남은 거리 · 구간 평균속도 · 과속 여부 | `onCameraAlert` | `NAVI_ROUTE` | 스쿨존 과속, 구간단속, 과속 |
| NaviHelper | 현재 도로 제한속도 | km/h, 1초마다 | `onCurrentRoadSpeedLimit` | `NAVI_ROUTE` | 30km/h 구간(보호구역 추정) |
| NaviHelper | 현재 위치 | 위도·경도·방향·주소·경로 위치 | `getCurrentLocationInfo` / 이벤트 | `NAVI_ROUTE` | 보호구역 사본과 대조 |

| NaviHelper | 교통 상황 | 정체 구간(도로명·교차로명·평균속도) · 사고·공사·재난 | `RouteStateInfo.trafficStatus` | `NAVI_ROUTE` | 사고·공사 구간 |

| NaviHelper | 목적지 도착 | 도착 이벤트 · 이름·주소·주행 거리/시간 | `onDestinationArrived` | `NAVI_ROUTE` | 주차 추정, 도착 후 안내 |

| AAOS Car API | 시동·주차 브레이크 | `IGNITION_STATE` · `PARKING_BRAKE_ON` | `CarPropertyManager` | `CAR_POWERTRAIN` | 주행 1회의 시작·끝, 주차 판정 |
| AAOS Car API | 운전 중 화면 제한 | 지금 화면 제한이 걸려 있는지 | `CarUxRestrictionsManager` | — | 주행 중 화면 막기, 주차 후 화면 열기 |

AAOS 행은 Pleos SDK가 아닌 Android Automotive 표준 API입니다. 기획 v6은 기어·차속을 이 API로 받는다고 전제합니다. Pleos 차에서 일반 앱에 열려 있는지는 문서에 없어 **검증이 필요합니다**. 열려 있으면 아래 '없는 정보'의 차량 속도·주차 상태가 풀립니다.

## 없는 정보

SDK에서 바로 받을 수 없는 정보입니다. 다른 신호로 추정하거나 운전자에게 물어야 합니다.

| 없는 정보 | 대안 |
| --- | --- |
| 차량 속도 | Pleos SDK에는 없습니다. AAOS Car API(`PERF_VEHICLE_SPEED`)로 받을 수 있는지 검증해야 합니다. 안 되면 위치와 시각으로 계산하는데, 정확도는 검증 전입니다 |
| 기어(P/D)·시동·주차 상태 | Pleos SDK에는 없고, 주차 브레이크가 들어 있는 경고등 정보는 시스템 앱 전용 권한(`PRIVATE_CAR_SAFETY`)이라 쓸 수 없습니다. AAOS Car API(기어·시동·주차 브레이크)가 열려 있는지 검증해야 합니다 |
| 경로 전체 (회전·주의 지점 목록, 경로 모양, 차로) | 다음 회전 1개와 다가오는 주의 지점만 옵니다 |
| 횡단보도·신호등 색·보행자 | Connect SDK에 없습니다. 아래 SDV OS API 참고 |
| 도로 종류 (고속도로·일반도로) | 전용 값이 없습니다. IC 진입·진출 안내, 경로 옵션, 크루즈 컨트롤로 추정하거나, 현재 위치를 한국도로공사 노선 좌표(기획 v6)와 대조합니다 |
| 날씨 | 없습니다. 와이퍼·안개등으로 추정합니다 |
| 운전자 구분 | 관련 API를 찾지 못했습니다. 한 차를 여러 사람이 몰면 확인 이력이 섞입니다 |
| 연료 종류 | 값 목록만 있고 조회 API는 찾지 못했습니다. 전기차 여부는 배터리 API 지원 여부로 추정합니다 |

### 횡단보도·신호등·보행자

Pleos 차량 OS(SDV OS, CODA OS)의 ADAS API에는 이 정보가 있습니다.

| API | 값 |
| --- | --- |
| `local_map` 영역 (`AreaType`) | `SafetyZone`, **`Crosswalk`** + 경계 좌표 |
| `local_map` 노면 표시 (`LineFeatureType`) | `StopLine`(정지선), `SpeedBump`, `CenterLine` 등 |
| `local_map` 표지판 (`TrafficSignType`) | `SchoolZone`, `Stop`, `Yield`, `Slow`, `UnderConstruction` |
| `local_map` 신호등 (`TrafficLightLampColor`) | **`Red` / `Yellow` / `Green`** |
| `tracked_objects` (`ObjectType`) | **`Pedestrian`**, `TwoWheeler`, `Bus`, `PoliceOfficer` 등 |

- 모두 센서가 지금 인식한 **차 주변** 정보입니다. 경로 앞쪽을 미리 알려 주지는 않습니다
- CODA OS용 Rust 앱이 쓰는 API입니다. Android 앱인 DRIVE RULE에서 부를 수 있는지는 문서에 없습니다

### 횡단보도는 공공 데이터로 추정

SDV OS API를 쓸 수 없다면, 어린이보호구역(`local_school_zone`)처럼 공공 데이터를 차량 DB에 받아 두고 대조합니다.

1. 공공데이터포털의 전국횡단보도표준데이터(좌표)를 카드 동기화 때 받아 둡니다
2. 회전 안내 `TURN_RIGHT`의 남은 거리와 현재 위치·진행 방향으로 회전 지점을 추정합니다
3. 회전 지점에서 회전 방향 쪽 일정 거리 안에 횡단보도가 있으면 '우회전 후 횡단보도' 카드를 고릅니다

지금 SDK만으로 되고, 위치도 차 밖으로 나가지 않습니다. 다만 회전 지점 좌표를 SDK가 주지 않아 추정이고, 경로 안내 중일 때만 됩니다.

## 언제 알 수 있나

주행 단계마다 알 수 있는 정보가 다릅니다. 알림 시점을 정할 때 기준으로 씁니다.

| 단계 | 알 수 있음 | 알 수 없음 |
| --- | --- | --- |
| 시동 직후·출발 전 | 목적지·경유지·남은 거리/시간·통행료(경로를 정했을 때), 즐겨찾기·최근 목적지, 주행 모드(에코·일반·스포츠), 누적 주행거리, 좌석별 착석·안전벨트(최대 3열), 차대번호(VIN) | **경로 위 회전·주의 지점 전체 목록** — 경로를 미리 펼쳐 보는 API가 없음. 날씨 |
| 주행 중 · 경로 안내 있음 | 다음 회전 1개와 남은 거리, 주의 지점·단속 카메라와 남은 거리, 도로 제한속도(1초마다), 정체·사고·공사, 방향지시등·조향각·브레이크·와이퍼·전조등·안개등 | 차량 속도, 신호등 색, 보행자, 차로, 횡단보도 |
| 주행 중 · 경로 안내 없음 | 위치·진행 방향, 차량 신호(방향지시등 등) | 다음 회전. 주의 지점·카메라·제한속도가 오는지는 **11/18 확인 필요** |
| 도착·주차 | 목적지 도착 이벤트, 문 열림, 안전벨트 해제, 이번 주행 시간·거리 | 기어 P·시동 꺼짐 — **Pleos SDK에는 주차를 확정하는 신호가 없음 (AAOS 검증 필요)** |

### 얼마나 앞서 알 수 있나

- 회전 안내는 **다음 회전 하나**만 옵니다. 몇 m 전부터 오는지는 문서에 없습니다. 기획 v6 이벤트 ③은 우회전 150m 전에 받는다고 전제합니다
- 주의 지점·카메라는 남은 거리(m)를 함께 주지만, 처음 알려 주는 거리는 문서에 없습니다
- 출발 전에 "오늘 경로에 스쿨존 3곳" 같은 경로 전체 브리핑은 어렵습니다. 지금 할 수 있는 것은 **목적지 주변** 대조입니다 (결정 007)
- 안내 거리와 문장 길이는 같이 정해야 합니다. 50km/h는 초당 약 14m라, 5초짜리 문장이 끝날 때까지 약 70m를 갑니다

## 법규 상황별 감지 가능성

'확실'은 SDK 값이 그 상황을 직접 가리키는 경우, '추정'은 여러 신호를 조합해야 하는 경우입니다.

| 법규 상황 | 감지 신호 | 판정 |
| --- | --- | --- |
| 어린이보호구역 진입 | 주의 지점 `SCHOOL_ZONE`, 스쿨존 카메라, 보호구역 사본 + 지오펜스 | 확실 |
| 우회전 | 회전 안내 `TURN_RIGHT` / 경로 없으면 방향지시등(오른쪽) + 조향각 | 경로 안내 중 확실, 아니면 추정 (차로 변경과 구분 못 함) |
| 우회전 후 횡단보도 | 공공 횡단보도 데이터 + 회전 지점 추정 | 추정 |
| 회전교차로 | 회전 안내 `TURN_ENTER_ROUNDABOUT_*` | 경로 안내 중 확실 |
| 유턴 | 회전 안내 `TURN_UTURN` | 경로 안내 중 확실 |
| 고속도로 진입 | 회전 안내 IC 진입, 경로 옵션 `HIGHWAY`, 크루즈 컨트롤 | 추정 |
| 터널 | 회전 안내 `TURN_TUNNEL` | 경로 안내 중 확실 |
| 꼬리물기 | 주의 지점 `BLOCK_INTERSECTION_ENFORCEMENT` | 단속 지점에서만 확실 |
| 버스전용차로 | 주의 지점 `BUS_LANE_*` | 확실 (알림 지점 기준) |
| 끼어들기 | 주의 지점 `CUT_IN_VIOLATION_ENFORCEMENT` | 단속 지점에서만 확실 |
| 철길 건널목 | 주의 지점 `RAILROAD_CROSSING` | 확실 |
| 과속 | 카메라 알림의 과속 여부, 구간 평균속도 | 카메라 근처만 확실. 그 밖은 위치로 계산한 속도라 추정 |
| 빗길·안개 | 와이퍼 작동·단계, 안개등, 주의 지점 `FOG_AREA`·`SLIPPERY_ROAD_ALERT` | 추정 |
| 야간 | 전조등 상태 + 시각 | 추정 |
| 뒷좌석 안전벨트 | 좌석별 착석 + 착용 (`CAR_SEATS`) | 확실 |
| 주정차 금지 | 주의 지점 `NO_PARKING_ZONE` + 도착 이벤트 | 추정 |
| 횡단보도 앞 일시정지·보행자 우선 | 없음 (SDV OS API라면 가능) | 불가 |
| 신호 관련(적색 우회전 등) | 신호등 색 없음 | 불가 — 지금처럼 운전자가 조건 토글로 답함 |
| 음주·휴대폰 사용 | 없음 | 불가 |
| 고속도로 정차·주차 | AAOS 기어 P + 한국도로공사 노선 좌표 대조 | 추정 — AAOS를 못 쓰면 불가 |
| 스쿨존 시간제 속도 (운영 변경) | 주의 지점 `SCHOOL_ZONE` + 도로 제한속도 + 운영 구간 목록 | 추정 — 내비 제한속도에 시간제가 반영되는지 미확인 |

### 기획 v6 이벤트와 대조

기획 v6이 P0로 정한 이벤트 3개(1-3 이벤트 정의)를 SDK로 판정할 수 있는지 대조했습니다.

| 이벤트 | v6 판정 조건 | SDK로 판정 | 걸리는 점 |
| --- | --- | --- | --- |
| ① 어린이보호구역 진입 | 시설 좌표 370m 안 | 가능 — FusedLocation 근접 알림(반경 370m)에 보호구역 사본을 등록. 경로 안내 중이면 주의 지점 `SCHOOL_ZONE`도 남은 거리를 줌 | 근접 알림 등록 개수 한도는 확인 못 함 — 가까운 곳만 바꿔 가며 등록해야 할 수 있음 |
| ② 주정차 · 목적지 | 목적지가 보호구역 300m 안이면 남은 거리 약 500m에서 | 가능 — `getDestinationInfo`의 좌표·남은 거리 | 경로 안내 중일 때만 |
| ② 주정차 · 고속도로 | 고속도로에서 기어가 P로 바뀔 때 | Pleos SDK로는 불가. AAOS 기어가 열려 있으면 가능 | 고속도로 여부는 노선 좌표 대조로 판단 |
| ③ 우회전 후 횡단보도 | 경로상 우회전 지점 약 150m 전 | 회전 지점은 가능 — `TURN_RIGHT` + 남은 거리(m). 횡단보도는 공공 데이터로 추정 | 회전 안내가 150m 전보다 먼저 오는지 미확인. 경로 안내가 없으면 불가 |

기획 v6 6장의 첫 항목 'NaviHelper가 회전 지점·고속도로 구간을 주는지'에 대한 답입니다. 회전 지점은 회전 안내(TBT)가 **남은 거리**로 줍니다(좌표는 없음). 고속도로 구간은 주지 않습니다. v6에 적힌 '확인된 것은 목적지·즐겨찾기·최근 목적지 조회뿐'은 조회 API만 본 것이고, 이벤트로 오는 회전 안내·주의 지점·카메라 알림이 더 있습니다.

## 기획에서 정할 것

상황 분류 값은 SDK의 주의 지점 종류와 회전 종류에 맞추는 것을 제안합니다. 주의 지점 종류는 꼬리물기, 버스전용차로, 끼어들기, 철길 건널목, 어린이보호구역처럼 법규 상황과 거의 그대로 맞아서, 앱에서 변환 없이 바로 대조할 수 있습니다.

1. **경로 안내를 켜지 않은 운전자.** 회전 안내는 경로 안내 중일 때만 온다고 봐야 합니다. 경로가 없으면 방향지시등과 조향각만 남는데, 이 둘로는 교차로 회전과 차로 변경을 구분하지 못합니다. 이 운전자에게 보여 줄 것(예: 출발 전 브리핑만)을 따로 정해야 합니다
2. **'주차한 뒤' 화면에 들어가는 조건.** Pleos SDK에는 주차를 확정하는 신호가 없습니다. AAOS 기어 P를 쓸 수 없으면 도착 이벤트 + 문 열림처럼 신호를 조합한 조건을 정해야 합니다
3. **속도 조건을 쓸지.** '정차 중', '저속일 때만 안내', 안내 시작 거리를 속도에 맞추기는 모두 차속이 필요합니다. AAOS 차속을 못 쓰면 위치 변화로 계산한 속도에 기대야 합니다
4. **차종별 카드는 차 안에서 거르기.** 차종은 차대번호(VIN)로만 압니다. VIN은 차를 특정하는 식별자라 서버로 보내지 않습니다 (결정 003). 차량 속성 필터(결정 001)는 차 안에서 해야 합니다
5. **내비 음성과 겹칠 때.** 회전 직전에는 내비도 말합니다. 순서를 조정하는 방법은 문서에서 찾지 못했습니다
6. **차마다 다른 내비 이벤트.** 문서에 "실제로 전달되는 이벤트는 내비 앱이 요청을 처리하는 방식에 따라 다를 수 있다"고 적혀 있습니다. 일부 이벤트가 오지 않아도 동작하게 기획해야 합니다
7. **'주행 1회'의 경계.** 기획 v6은 주행 1회당 최대 2건을 안내합니다. 시동 신호를 못 받으면 주행의 시작·끝을 다른 신호로 정해야 합니다 (예: Vehicle SDK의 '이번 주행 시간'이 처음부터 다시 세질 때)
8. **주행 중 앱이 먼저 말해도 되는지.** 이벤트 안내 전체가 여기에 걸려 있습니다 (기획 v6 6장). Pleos 문서에서 규정을 찾지 못했습니다

## 11/18 기술 검증 항목

- [ ] 경로 안내 없이 달릴 때 회전 안내·주의 지점·카메라·제한속도 이벤트가 오는가
- [ ] 회전 안내가 회전 몇 m 전부터 오는가, 다음 회전 하나만 오는가
- [ ] 주의 지점·카메라가 몇 m 전부터 오는가
- [ ] 회전 안내 문구(`description`)에 회전 뒤 도로 정보가 들어오는가
- [ ] 주차 상태를 알 방법이 있는가 (운전 제한 정책 가이드)
- [ ] 위치 변화로 계산한 속도가 정차·저속 판단에 쓸 만큼 정확한가
- [ ] 좌석별 착석·안전벨트(`CAR_SEATS`)를 앱 권한으로 읽을 수 있는가
- [ ] DRIVE RULE 앱에서 SDV OS ADAS API(`local_map`·`tracked_objects`)를 부를 수 있는가
- [ ] 우리 TTS가 내비 음성과 겹치면 어떻게 되는가
- [ ] TTS 온디바이스 모드가 통신 없이 동작하는가 (터널 등)
- [ ] AAOS Car API(기어·차속·시동·주차 브레이크)를 일반 앱 권한으로 읽을 수 있는가
- [ ] FusedLocation 근접 알림을 몇 곳까지 등록할 수 있는가
- [ ] 내비 도로 제한속도에 스쿨존 시간제 속도가 반영되는가
- [ ] '이번 주행 시간'이 시동마다 처음부터 다시 세는가
- [ ] 주행 중 앱이 먼저 음성 안내를 해도 되는가 (Pleos 문의)
