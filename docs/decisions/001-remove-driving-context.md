# 001. 운전자 프로필에서 '운전 상황' 제외

- 날짜: 2026-11-11
- 상태: 결정 (MVP 범위)
- 관련: `docs/db/erd.data.mjs` — `driver_profile.driving_context`, `rule_card.audience` 삭제

## 배경

- 기획 v5: 프로필 등록 시 "이름·운전 상황"을 입력 (시나리오 3)
- 기획 1번 비교표: "나에게 해당하는지 = 면허 시점·운전 상황"으로 판단

## 결정

- 프로필 입력은 **이름만** 받는다
- 카드의 '적용 대상'(`audience`)도 함께 뺀다 — 운전 상황과 짝을 이루던 값이라 혼자 남으면 쓰이지 않는다

## 이유

- **정의가 없다**: 운전 상황의 값 목록, 그 값으로 무엇을 거르는지가 기획 어디에도 없다
- **판단 근거가 이미 빠졌다**: '나에게 해당' 판단에 쓰던 면허 취득 연월이 v5 에서 삭제됨
- **필터링은 게시 전에 끝난다**: 기능 ⑦ "일반 운전자 해당분만 안내" — 분류 단계에서 거른 카드만 게시되므로 프로필로 다시 거를 대상이 없다
- 정의 없이 넣으면 입력 화면·컬럼만 생기고 동작은 없다 (출발 전 알림 흐름만 한 단계 늘어남)

## 영향

- 게시된 카드는 모든 일반 운전자에게 해당한다고 본다
- 기획서 문구 수정 필요 (Notion 미반영)
  - 시나리오 3: "이름·운전 상황을 등록" → "이름을 등록"
  - 1번 비교표: "면허 시점·운전 상황" → "게시 전 일반 운전자 해당분만 선별"

## 다시 검토할 때

- 일부 운전자에게만 해당하는 카드를 앱에서 골라 보여 줘야 할 때 (예: 초보·고령 운전자 전용 안내)
- 그때는 값 목록과 거르는 규칙을 먼저 정한 뒤 `driver_profile` 과 `rule_card` 에 함께 추가한다

## 함께 정한 것 — 렌터카·카셰어링 익명 모드도 MVP 제외

- 기획: "익명으로 동작하며 시동이 꺼지면 이력을 지운다" — PT 시연 6단계에 없음, B2B 는 3단계(2029~) 계획
- 프로필 컬럼(`is_anonymous`)으로 두지 않는다. 도입 시 기기 설정 + 시동 종료 시 이력 삭제로 구현
